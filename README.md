One emoji for one dream vacation: **🗻 Mount Fuji at sunrise** — a snow-capped
peak at dawn, the trip of a lifetime in a single glance.

## Entry

The program writes exactly one emoji to `/output/entry.txt`:

```
🗻
```

## Why this emoji

Five candidates were judged pairwise (twice each, positions swapped) against
the judge's own rubric — lands on a dream vacation, vivid at a glance,
personal and specific, a spark of wit, reads instantly:

| Candidate | Dream | What it evokes |
| --- | --- | --- |
| 🗻 Mount Fuji | Climb Fuji at sunrise | An iconic peak, a postcard with no words needed |
| 🌋 Volcano | Sunrise hike on a volcano | Dramatic, but reads as eruption as easily as a trip |
| 🌌 Milky Way | Stargazing in the mountains | A grand sky, but a sky you can see from a backyard |
| 🐋 Whale | Swim with whales | A great encounter, but an animal, not a place |
| 🦩 Flamingo | A pink lagoon | Fresh and witty, but reads as zoo as easily as a trip |

Mount Fuji won every pairing (8–0): it is the only candidate that is at once
a place, a postcard, and a specific dream — one mountain, one sunrise, one
trip you would cross the world for.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22. No dependencies, no network.
